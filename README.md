# Fortune Cookie Funnies for Engineers

A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) entry: one fortune-cookie line for a software engineer, 120 characters or fewer.

`main.py` (Python 3.13, standard library only) writes the fortune to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no
trailing newline.

The fortune stacks three punchlines on the classic "lucky numbers"
guardrail: 418, then 429, then the port you left open in prod —
and the twist is that your "lucky" numbers are all error codes
and your own open port, so the cookie ends with an ironic
"Good luck — you'll need it."

## Run

```sh
python3 main.py
```
